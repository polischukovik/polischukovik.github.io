What This Proves

  • Browser can generate PKCE verifier and challenge.
  • Genesys can redirect back to the static page with an authorization code.
  • Browser can exchange that code for tokens without a backend relay.
  • Browser can call a required Genesys analytics API directly with the access token.
  • Browser can call the exact bot flow detail endpoints needed for recent-mode calculations.
  • Browser can discover and load tenant config from Genesys Content Management.
